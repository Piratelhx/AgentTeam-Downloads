# AgentTeam 产品功能介绍

AgentTeam 是连接本机 Claude Code 的 Windows 桌面客户端。产品经理可以私聊某位 AI 角色，也可以选择场景建立固定团队，由成员逐位接力完成需求分析、方案评审或产品调研。

## 群聊中完成工作

![群聊与文档交付](images/01_group_overview.png)

群里直接说需求时，默认按场景分工执行。也可以输入 @ 指定已有成员；成员完成后可通过 @ 接力交给下一位。每条回复保留角色与时间，任务中可停止，同一时刻只有一位成员处理。

## 三个内置场景


- **需求分析与 PRD 编写**：业务分析师梳理目标、用户与规则，交互设计师补充流程和异常，技术评估师识别依赖与风险，产品经理输出完整 PRD 和验收标准。
- **产品方案模拟评审**：产品经理明确范围，专家独立审查，再对真实争议进行最多两轮交叉回应。保留未决分歧，形成结论与具体修改建议。
- **产品机会调研**：市场、用户、质量角色依次研究和核验，产品经理整合机会、MVP 与验证计划。资料记录来源日期，缺少证据时明确标记假设。

## 资料上传与群文件

![群文件](images/02_group_files.png)

加号用于上传文档，禁止图片。单个文件最多 20 MB，一次最多 10 个、总计 50 MB。上传资料和成员生成的 Markdown 文档在群文件中集中管理，支持分类、搜索、预览和下载。桌面版还可打开文件或在本机文件夹中显示。

## 消息编辑和协作记录

消息支持复制与完整时间记录。用户编辑历史消息并提交后，从该条消息之后的对话及关联群文件记录会被替换并重新生成；已经写入项目目录的原文件不会自动回滚。

## 自定义角色与工作方法

Agent 可以配置名称、职责、System Prompt、项目目录和本地 Skill。场景定义目标、成员、逐项分工顺序、最后汇总者与交付要求，支持增删改查和导入导出。修改模板用于后续新建的群聊，已有群聊保留原有配置。

## 本地 Skill


扫描和添加本地 Skill 目录，搜索名称或用途，逐项勾选或全选挂载。查看内容时打开独立阅读界面，支持阅读视图和源文件视图。每位 Agent 可挂载不同 Skill。

## 连接与安装更新

仅提供 Windows x64 EXE 安装版。支持选择目录、覆盖确认及完成后打开。使用者需要在自己的电脑安装并登录 Claude Code，点击客户端的“测试 Claude Code”验证真实回复。模型可使用本机默认设置，处理深度可选深入或标准。

设置页显示当前版本，支持检查更新、后台新版提醒、签名校验、差异下载及完整包断点续传。聊天和配置保留；任务进行时不能重启安装。
